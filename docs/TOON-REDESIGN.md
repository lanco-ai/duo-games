## 字体

- 中文：站酷快乐体（SIL OFL 1.1）；英文和数字：Fredoka 粗体实例（SIL OFL 1.1）。两款都只截取需要的字符，体积约 71 KB + 11 KB，`font-display: swap`。
- 许可文件在 `web/src/assets/fonts/OFL-*.txt`；关于弹窗里有署名。
- **新增界面文案后要重新生成子集**，否则新字会回退到系统字体：
  ```bash
  python3 -m venv /tmp/fontenv && /tmp/fontenv/bin/pip install fonttools brotli
  /tmp/fontenv/bin/python scripts/subset-font.py ZCOOLKuaiLe-Regular.ttf "Fredoka[wdth,wght].ttf"
  ```
- 词语、题目、昵称这类动态内容统一用系统粗体，不混用两种字体。

## 两条必须遵守的约束

1. **不要写 `infinite` 的 CSS 动画**。在 1 核服务器的无头浏览器里，常驻动画会让 Playwright 的 trace 录像一直在录帧，测试慢 3–5 倍并超时；在低端手机上也一直耗电。装饰动画一律有限次（小动物进场蹦 3 下）。游戏进行中，背景和小动物的装饰动画全部暂停（`.room-page.playing`）。
2. **可点击元素本身不做持续位移动画**。Playwright 要等元素稳定才会点击，真机上点一个一直在动的按钮也不可靠；要动就动按钮里面的装饰元素。
