## 核查结论与修复

1. **画板与拼图坐标偏差（P2）**：卡通版为画板增加 10px 边框、拼图增加 4px 边框，原指针映射包含边框，画笔和拖拽会偏离实际内容。新增 `canvas-point.ts` 按 CSS 内容盒映射，处理边框、内边距、CSS 缩放和高 DPI；画板保持 0–1000 逻辑坐标，拼图保持其画布坐标。
2. **旧浏览器迷宫宽度（P2）**：使用含 `var()` 的 `svh` 声明时，旧浏览器可能在计算阶段才发现单位无效，普通的前置 `vh` 声明不会恢复。基础规则改用 `vh`，仅在 `@supports (height: 1svh)` 内使用 `svh`。浏览器回归将 `svh` 替换为未知单位，保留真实的无效计算路径，检查双人迷宫尺寸。
3. **发布记录过期（P2）**：核查时实际生产为 `20261023T140722Z`，但 release-id、backup-dir 和多份 JSON 仍指向更早版本。本次发布后统一生成当前版本、备份、Git 源码提交和文件摘要，旧证据按对应版本归档。
4. **数据库与照片备份一致性**：继续以服务账号执行 SQLite 在线 `backup()`，复制照片后，按备份数据库逐条校验照片文件存在、是普通文件且大小一致。任一检查失败就废弃该轮临时备份并重新快照/复制；旧的有效备份始终保留。图片 UUID 文件只写一次，因此校验后的副本可完整满足快照引用，无需停止业务备份。
