# 红绳与一线牵修复（2026-10-24，北京时间）

用户授权修复、上线和部署，并要求在测试阶段能亲自试玩。沿用不使用工作流的要求。

## 修复

- 首页、大厅和状态页改为共用一个 SVG 人物与红绳组件，端点连接在角色躯干内；整组使用同一跳动动画，避免角色动而绳端不动。
- 攀绳横向速度改为指向锚点的固定速度，不再逐帧累加；正常第一关输入路径复现的异常横向加速已纳入回归。
- 键盘与触摸按物理输入源分别记录；松开一个同义键不清掉其他按键，切入聊天输入框/失焦/暂停时清空输入，松键不再因焦点位于输入框而被忽略。
- 正在自行抓墙的人不算被绳子吊住，避免双人各自抓墙时误计救援。
- 物理规则在前后端共享。通信版本升为 3，旧页面收到刷新提示，避免新旧模拟混用。
- 测试入口 `/duo-preview/` 使用独立数据库、照片目录、服务、请求配额及浏览器房间凭证；页面明确标记测试版。
